Set up Hearth on this device

Hearth uses a private certificate so messages and files stay encrypted on the home network. Every device needs to trust it once — it's a one-time step.

On a phone: scan this

Or open this page directly on the phone's browser.

iPhone / iPad

  1. Tap Download certificate — Safari downloads a profile.
  2. Go to Settings → General → VPN & Device Management, tap the downloaded profile, then Install.
  3. Then go to Settings → General → About → Certificate Trust Settings and turn on full trust for it. (Easy to miss — both steps are required.)

Android

  1. Tap Download certificate.
  2. Open it from your notifications or Downloads — Android will prompt to install it as a CA certificate. Confirm.

On a laptop

Download certificate

macOS

  1. Double-click the downloaded file — Keychain Access opens.
  2. Find the certificate (named "mkcert ..."), double-click it, expand Trust, and set "When using this certificate" to Always Trust.
  3. Close the window and enter your password to confirm.

Windows

  1. Double-click the downloaded file, then Install Certificate.
  2. Choose Local Machine (or Current User), then Place all certificates in the following store → Trusted Root Certification Authorities.
  3. Finish, and confirm the security prompt.

Done installing? Open Hearth at https://homebot.local:8443 (adjust the port if it was changed) — no more warnings.
